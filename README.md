# Make Joomla CLI-ing

This repository contains the materials for the "Make Joomla CLI-ing" presentation, delivered at two different JoomlaDay events: JoomlaDay USA and JoomlaDay France.

Each event folder includes:
*   **`README.md`**: Information specific to the event.
*   **`extension/`**: Source code for the Joomla CLI extension demonstrated during the presentation.
*   **`mockup-data/`**: Sample data used for demonstrations.
*   **`slides/`**: Presentation slides in various formats.
